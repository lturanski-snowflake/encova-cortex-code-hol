# Admin: Provision Attendees

**Run by:** Luke (SE) at the start of the lab session  
**Role required:** ACCOUNTADMIN  
**Prerequisite:** `attendees.txt` is populated with one attendee first name per line (uppercase)

---

### CoCo Prompt

```
Read the file attendees.txt in this workspace. It contains one attendee first name 
per line (uppercase). Generate a SQL file called sql/01c_provision_attendees.sql 
that I can run directly. The file should start with USE ROLE ACCOUNTADMIN; and then 
for EACH name in attendees.txt, include:

1. CREATE DATABASE IF NOT EXISTS TRAINING_<NAME>
     COMMENT = 'Attendee workspace — <NAME>';

2. CREATE SCHEMA IF NOT EXISTS TRAINING_<NAME>.BRONZE
     COMMENT = 'Bronze layer — parsed and validated';

3. CREATE SCHEMA IF NOT EXISTS TRAINING_<NAME>.SILVER
     COMMENT = 'Silver layer — enriched with AI';

4. CREATE SCHEMA IF NOT EXISTS TRAINING_<NAME>.GOLD
     COMMENT = 'Gold layer — aggregated metrics';

5. GRANT OWNERSHIP ON DATABASE TRAINING_<NAME>
     TO ROLE ATTENDEE_ROLE COPY CURRENT GRANTS;

6. GRANT OWNERSHIP ON SCHEMA TRAINING_<NAME>.BRONZE
     TO ROLE ATTENDEE_ROLE COPY CURRENT GRANTS;

7. GRANT OWNERSHIP ON SCHEMA TRAINING_<NAME>.SILVER
     TO ROLE ATTENDEE_ROLE COPY CURRENT GRANTS;

8. GRANT OWNERSHIP ON SCHEMA TRAINING_<NAME>.GOLD
     TO ROLE ATTENDEE_ROLE COPY CURRENT GRANTS;

Write the complete file — do NOT execute it. Just generate it so I can review 
and run it myself.
```

---

### What This Does

Generates `sql/01c_provision_attendees.sql` with all DDL expanded for every attendee. You then run it in one shot (faster than CoCo executing statements one by one).

For each name in `attendees.txt`, it creates:

| Resource | Pattern | Example (for "LUKE") |
|----------|---------|---------------------|
| Database | `TRAINING_<NAME>` | `TRAINING_LUKE` |
| Schemas | `BRONZE`, `SILVER`, `GOLD` | `TRAINING_LUKE.BRONZE` |

All owned by `ATTENDEE_ROLE`. Raw data lives in the shared `ENCOVA_TRAINING.RAW_DATA`.

---

### After Provisioning

Each attendee sets their context once at the start of the lab:

```sql
USE ROLE ATTENDEE_ROLE;
USE DATABASE TRAINING_<NAME>;
USE WAREHOUSE ENCOVA_TRAINING_WH;
```

This is handled by the **Module 0.1 — Set Context** prompt.
