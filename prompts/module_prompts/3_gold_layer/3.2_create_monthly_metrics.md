# Module 3.2 — Create Monthly Metrics Gold

**Paste into Cortex Code:**

```
Use skill .cortex/skills/encova-context/SKILL.md. Create a Dynamic Table called 
CLAIMS_METRICS_MONTHLY in my GOLD schema with TARGET_LAG = DOWNSTREAM that 
aggregates GOLD.CLAIMS_GOLD by:
- LOSS_MONTH (DATE_TRUNC month on DATE_OF_LOSS)
- LINE_OF_BUSINESS
- LOSS_LOCATION_STATE
- SEVERITY

Include: CLAIM_COUNT, TOTAL_ESTIMATED, TOTAL_PAID, TOTAL_INCURRED, 
AVG_CLAIM_AMOUNT, AVG_DAYS_TO_REPORT, SUSPICIOUS_COUNT, LITIGATION_COUNT, 
WEATHER_CLAIMS count, COMPLEX_CLAIMS count.

For AVG_SENTIMENT, map DESCRIPTION_SENTIMENT strings to numbers:
  'positive' → 1.0, 'neutral' → 0.0, 'negative' → -1.0, else 0.0
Then AVG() that expression.

After creating, run: ALTER DYNAMIC TABLE GOLD.CLAIMS_METRICS_MONTHLY REFRESH;
```

> **Dynamic Table Dependencies:** Because this table queries CLAIMS_GOLD, 
> Snowflake auto-detects the dependency. `TARGET_LAG = DOWNSTREAM` means it 
> refreshes after CLAIMS_GOLD finishes — no manual schedule needed.
