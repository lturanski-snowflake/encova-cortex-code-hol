# Module 2.2 — Create Silver Claim Notes

**Paste into Cortex Code:**

```
Use skill .cortex/skills/medallion-pipeline/SKILL.md. Create a Dynamic Table 
called CLAIM_NOTES_SILVER in my SILVER schema with TARGET_LAG = '5 minutes' 
that reads from BRONZE.CLAIM_NOTES.

No AI functions needed here — use simple keyword-based sentiment instead:

CASE 
  WHEN LOWER(NOTE_TEXT) LIKE '%suspicious%' OR LIKE '%denied%' 
       OR LIKE '%frustrated%' OR LIKE '%fraud%' THEN 'NEGATIVE'
  WHEN LOWER(NOTE_TEXT) LIKE '%approved%' OR LIKE '%satisfact%' 
       OR LIKE '%completed%' OR LIKE '%resolved%' THEN 'POSITIVE'
  ELSE 'NEUTRAL'
END AS SENTIMENT_CATEGORY

Include columns: NOTE_ID, CLAIM_ID, NOTE_DATE, NOTE_AUTHOR, NOTE_TYPE, 
NOTE_TEXT, SENTIMENT_CATEGORY, SILVER_LOADED_AT.

After creating the DT, run: ALTER DYNAMIC TABLE SILVER.CLAIM_NOTES_SILVER REFRESH;
Then SELECT COUNT(*) FROM SILVER.CLAIM_NOTES_SILVER to confirm.
```
