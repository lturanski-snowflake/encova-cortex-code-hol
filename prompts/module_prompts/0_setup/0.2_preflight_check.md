# Module 0.2 — Pre-Flight Check

Verify your environment is ready before the lab begins.

**Paste into Cortex Code:**

```
USE ROLE ATTENDEE_ROLE;
USE DATABASE TRAINING_<NAME>;
USE WAREHOUSE ENCOVA_TRAINING_WH;

Confirm my setup:
1. Show me the schemas in my TRAINING_<NAME> database
2. Show me the tables in the RAW_DATA schema of ENCOVA_TRAINING 
   (the shared source data we'll load from)
3. Run a quick Cortex AI test: 
   SELECT AI_SENTIMENT('The claim was processed quickly and the customer is satisfied.');
```

You should see:
- Your database has **BRONZE**, **SILVER**, and **GOLD** schemas (empty — you'll build the pipeline)
- `ENCOVA_TRAINING.RAW_DATA` has **5 tables**: CLAIMS_RAW, POLICIES, CLAIMANTS, CLAIM_NOTES, AGENTS
- The sentiment test returns an object with `"overall": "positive"`

> The source data is already loaded in the shared `ENCOVA_TRAINING` database.  
> You'll copy it into your own Bronze → Silver → Gold pipeline in the next modules.
